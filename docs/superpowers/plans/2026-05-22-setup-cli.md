# Setup CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single interactive `pnpm setup` CLI (`scripts/setup/index.ts`) that automates the post-implementation environment setup — secret generation, DB migrations, Stripe product creation, Clerk webhook registration, Resend domain registration, and branding replacement — supporting both interactive local dev mode and headless `--ci` mode.

**Architecture:** Eight focused modules in `scripts/setup/`. Pure utilities (env file merge, secret generation, branding replacement) are extracted into `scripts/setup/utils/` and fully unit-tested. Side-effecting modules (db, stripe, clerk, resend) live in `scripts/setup/modules/` and are verified via TypeScript type-checking only. The main entry point uses `@clack/prompts` for interactive mode and respects `--ci` plus individual `--skip-*` flags for headless operation. Secrets are written to `apps/web/.env.local` using dotenv-merge semantics — existing values are never overwritten.

**Tech Stack:** `tsx` (existing root devDep), `@clack/prompts` (interactive prompts), `commander` (flag parsing), `stripe` Node SDK, `dotenv` (env file parsing), Node.js built-in `crypto` (secret generation), Node.js `fs` + `child_process` (file I/O, shell exec)

export type EnvMap = Record<string, string>;

export function parseEnvFile(content: string): EnvMap {
  const result: EnvMap = {};
  for (const raw of content.split("\n")) {
    const line = raw.trim();
    if (!line || line.startsWith("#")) continue;
    const eqIdx = line.indexOf("=");
    if (eqIdx === -1) continue;
    const key = line.slice(0, eqIdx).trim();
    const rawVal = line.slice(eqIdx + 1);
    const value = rawVal.split(" #")[0].trim();
    if (key) result[key] = value;
  }
  return result;
}

export function mergeEnv(existing: EnvMap, incoming: EnvMap): EnvMap {
  const merged = { ...existing };
  for (const [key, value] of Object.entries(incoming)) {
    if (!(key in merged)) {
      merged[key] = value;
    }
  }
  return merged;
}

export function serializeEnv(env: EnvMap): string {
  return (
    Object.entries(env)
      .map(([k, v]) => `${k}=${v}`)
      .join("\n") + "\n"
  );
}

export function getEnvValue(env: EnvMap, key: string): string | undefined {
  const val = env[key];
  return val !== undefined && val.length > 0 ? val : undefined;
}
```

export interface DbResult {
  success: boolean;
  error?: string;
}

export function runMigrations(cwd: string = process.cwd()): DbResult {
  const databaseUrl = process.env.DATABASE_URL;
  if (!databaseUrl) {
    return {
      success: false,
      error:
        "DATABASE_URL is not set. Add it to apps/web/.env.local or export it in your shell.",
    };
  }

  try {
    execSync("pnpm --filter @smm/db migrate", {
      cwd,
      stdio: "inherit",
      env: { ...process.env, DATABASE_URL: databaseUrl },
    });
    return { success: true };
  } catch (err) {
    return {
      success: false,
      error: err instanceof Error ? err.message : String(err),
    };
  }
}
```

export interface StripeSetupResult {
  growthPriceId: string;
  agencyPriceId: string;

  secretKey: string;
  webhookUrl?: string;

export async function setupStripe(
  opts: StripeModuleOptions,
): Promise<StripeSetupResult> {
  const stripe = new Stripe(opts.secretKey, { apiVersion: "2024-06-20" });

  const growthProduct = await stripe.products.create({ name: "Growth" });
  const growthPrice = await stripe.prices.create({
    product: growthProduct.id,
    unit_amount: 9900,
    currency: "usd",
    recurring: { interval: "month" },
  });

  const agencyProduct = await stripe.products.create({ name: "Agency" });
  const agencyPrice = await stripe.prices.create({
    product: agencyProduct.id,
    unit_amount: 29900,
    currency: "usd",
    recurring: { interval: "month" },
  });

  const result: StripeSetupResult = {
    growthPriceId: growthPrice.id,
    agencyPriceId: agencyPrice.id,
  };

  if (opts.webhookUrl) {
    const webhook = await stripe.webhookEndpoints.create({
      url: opts.webhookUrl,
      enabled_events: [
        "checkout.session.completed",
        "customer.subscription.updated",
        "customer.subscription.deleted",
      ],
    });
    result.webhookSecret = webhook.secret ?? undefined;
  }

  return result;
}

export async function setupClerkWebhook(
  opts: ClerkModuleOptions,
): Promise<ClerkWebhookResult> {
  const response = await fetch("https://api.clerk.com/v1/webhooks", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${opts.secretKey}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      url: opts.endpointUrl,
      event_types: ["organization.created", "user.created"],
    }),
  });

  if (!response.ok) {
    const body = await response.text();
    throw new Error(`Clerk API error ${response.status}: ${body}`);
  }

  const data = (await response.json()) as { signing_secret: string };
  return { signingSecret: data.signing_secret };
}

export interface DnsRecord {
  type: string;
  name: string;
  value: string;
  ttl?: number;
}

export interface ResendDomainResult {
  domainId: string;
  dnsRecords: DnsRecord[];
}

export interface ResendModuleOptions {
  apiKey: string;
  domain: string;
}

export async function setupResendDomain(
  opts: ResendModuleOptions,
): Promise<ResendDomainResult> {
  const response = await fetch("https://api.resend.com/domains", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${opts.apiKey}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ name: opts.domain }),
  });

  if (!response.ok) {
    const body = await response.text();
    throw new Error(`Resend API error ${response.status}: ${body}`);
  }

  const data = (await response.json()) as {
    id: string;
    records: DnsRecord[];
  };

  return { domainId: data.id, dnsRecords: data.records ?? [] };
}

export function formatDnsRecords(records: DnsRecord[]): string {
  if (records.length === 0) return "  (no records returned)";
  return records
    .map((r) => `  ${r.type.padEnd(6)} ${r.name.padEnd(50)} ${r.value}`)
    .join("\n");
}
```

import { program } from "commander";
import { readFileSync, writeFileSync, existsSync } from "fs";

import * as clack from "@clack/prompts";

  else clack.log.error(msg);
}

  .option(
    "--skip-secrets",
    "Skip generating PORTAL_SECRET / INSTAGRAM_TOKEN_KEY",
  )
  .option("--skip-db", "Skip database migrations")
  .option("--skip-stripe", "Skip Stripe product/webhook setup")
  .option("--skip-clerk", "Skip Clerk webhook setup")
  .option("--skip-resend", "Skip Resend domain setup")
  .option("--skip-branding", "Skip branding text replacement")
  .option("--brand-name <name>", "Brand name for CI mode (skips prompt)")
  .option("--app-url <url>", "App URL for CI mode (used for webhook endpoints)")
  .action(async (opts) => {
    const ci = Boolean(opts.ci);

    if (!ci) clack.intro("SMM Therapy — Post-Implementation Setup");

    const env = readEnv();

    // ── Secrets ────────────────────────────────────────────────────────────
    if (!opts.skipSecrets) {
      const needsPortal = !env.PORTAL_SECRET;
      const needsIgKey = !env.INSTAGRAM_TOKEN_KEY;

      if (needsPortal || needsIgKey) {
        const spin = ci ? null : clack.spinner();
        spin?.start("Generating secrets");

        if (needsPortal) env.PORTAL_SECRET = generateHexSecret();
        if (needsIgKey) env.INSTAGRAM_TOKEN_KEY = generateHexSecret();
        writeEnv(env);

        spin?.stop("Secrets written to apps/web/.env.local");
        if (ci) console.log("[setup] Generated secrets → apps/web/.env.local");
      } else {
        log(ci, "Secrets already set — skipping generation");
      }
    }

    // ── Database ───────────────────────────────────────────────────────────
    if (!opts.skipDb) {
      const databaseUrl = env.DATABASE_URL ?? process.env.DATABASE_URL;
      if (!databaseUrl) {
        warn(
          ci,
          "DATABASE_URL not found — skipping migrations. Add it to apps/web/.env.local and re-run with --skip-secrets.",
        );
      } else {
        process.env.DATABASE_URL = databaseUrl;
        const spin = ci ? null : clack.spinner();
        spin?.start("Running database migrations");

        const result = runMigrations();
        if (result.success) {
          spin?.stop("Migrations applied");
          if (ci) console.log("[setup] Migrations applied");
        } else {
          spin?.stop("Migration failed");
          logError(ci, result.error ?? "Unknown migration error");
          if (ci) process.exit(1);
        }
      }
    }

    // ── Stripe ─────────────────────────────────────────────────────────────
    if (!opts.skipStripe) {
      const stripeKey = env.STRIPE_SECRET_KEY ?? process.env.STRIPE_SECRET_KEY;
      if (!stripeKey) {
        warn(
          ci,
          "STRIPE_SECRET_KEY not set — skipping Stripe setup. Add it and re-run with --skip-db --skip-secrets.",
        );
      } else {
        let webhookUrl: string | undefined;

        if (!ci) {
          const input = await clack.text({
            message:
              "App URL for Stripe webhook (leave blank for local dev — use Stripe CLI instead):",
            placeholder: "https://yourdomain.com",
          });
          if (!clack.isCancel(input) && input) {
            webhookUrl = `${input}/api/webhooks/stripe`;
          }
        } else if (opts.appUrl) {
          webhookUrl = `${opts.appUrl}/api/webhooks/stripe`;
        }

        const { setupStripe } = await import("./modules/stripe.js");
        const spin = ci ? null : clack.spinner();
        spin?.start("Creating Stripe products and prices");

        try {
          const result = await setupStripe({
            secretKey: stripeKey,
            webhookUrl,
          });
          const updated = mergeEnv(env, {
            STRIPE_PRICE_GROWTH: result.growthPriceId,
            STRIPE_PRICE_AGENCY: result.agencyPriceId,
            ...(result.webhookSecret
              ? { STRIPE_WEBHOOK_SECRET: result.webhookSecret }
              : {}),
          });
          Object.assign(env, updated);
          writeEnv(env);

          spin?.stop(
            `Stripe configured — Growth: ${result.growthPriceId}  Agency: ${result.agencyPriceId}`,
          );
          if (ci) {
            console.log(
              `[setup] Stripe → Growth: ${result.growthPriceId}, Agency: ${result.agencyPriceId}`,
            );
          }

          if (!webhookUrl) {
            log(
              ci,
              "No webhook URL provided. For local dev run: stripe listen --forward-to localhost:3000/api/webhooks/stripe",
            );
          }
        } catch (err) {
          spin?.stop("Stripe setup failed");
          logError(ci, err instanceof Error ? err.message : String(err));
        }
      }
    }

    // ── Clerk webhook ──────────────────────────────────────────────────────
    if (!opts.skipClerk) {
      const clerkKey = env.CLERK_SECRET_KEY ?? process.env.CLERK_SECRET_KEY;
      if (!clerkKey) {
        warn(ci, "CLERK_SECRET_KEY not set — skipping Clerk webhook setup.");
      } else {
        let appUrl: string | undefined;

        if (!ci) {
          const input = await clack.text({
            message: "App URL for Clerk webhook:",
            placeholder: "https://yourdomain.com",
          });
          if (!clack.isCancel(input)) appUrl = input as string;
        } else {
          appUrl = opts.appUrl;
        }

        if (!appUrl) {
          warn(ci, "No app URL — skipping Clerk webhook setup.");
        } else {
          const { setupClerkWebhook } = await import("./modules/clerk.js");
          const spin = ci ? null : clack.spinner();
          spin?.start("Registering Clerk webhook");

          try {
            const result = await setupClerkWebhook({
              secretKey: clerkKey,
              endpointUrl: `${appUrl}/api/webhooks/clerk`,
            });
            const updated = mergeEnv(env, {
              CLERK_WEBHOOK_SECRET: result.signingSecret,
            });
            Object.assign(env, updated);
            writeEnv(env);
            spin?.stop("Clerk webhook registered");
            if (ci) console.log("[setup] Clerk webhook registered");
          } catch (err) {
            spin?.stop("Clerk webhook setup failed");
            logError(ci, err instanceof Error ? err.message : String(err));
          }
        }
      }
    }

    // ── Resend domain ──────────────────────────────────────────────────────
    if (!opts.skipResend) {
      const resendKey = env.RESEND_API_KEY ?? process.env.RESEND_API_KEY;
      if (!resendKey) {
        warn(ci, "RESEND_API_KEY not set — skipping Resend domain setup.");
      } else {
        let domain: string | undefined;

        if (!ci) {
          const input = await clack.text({
            message: "Your sending domain for Resend (e.g. yourdomain.com):",
            placeholder: "yourdomain.com",
          });
          if (!clack.isCancel(input) && input) domain = input as string;
        }

        if (!domain) {
          log(
            ci,
            "No domain provided — skipping Resend. Emails will use onboarding@resend.dev until you set up a domain.",
          );
        } else {
          const { setupResendDomain, formatDnsRecords } =
            await import("./modules/resend.js");
          const spin = ci ? null : clack.spinner();
          spin?.start(`Registering ${domain} with Resend`);

          try {
            const result = await setupResendDomain({
              apiKey: resendKey,
              domain,
            });
            spin?.stop(`Domain registered (id: ${result.domainId})`);
            log(
              ci,
              `Add these DNS records to verify ${domain}:\n${formatDnsRecords(result.dnsRecords)}`,
            );
          } catch (err) {
            spin?.stop("Resend domain setup failed");
            logError(ci, err instanceof Error ? err.message : String(err));
          }
        }
      }
    }

    // ── Branding ───────────────────────────────────────────────────────────
    if (!opts.skipBranding) {
      let brandName: string | undefined = opts.brandName as string | undefined;

      if (!brandName && !ci) {
        const input = await clack.text({
          message:
            "Product brand name (replaces 'TherapyContent' in marketing pages):",
          placeholder: "MyProduct",
        });
        if (!clack.isCancel(input) && input) brandName = input as string;
      }

      if (!brandName) {
        log(ci, "No brand name — skipping branding replacement.");
      } else {
        let replaced = 0;
        for (const relPath of BRANDING_FILES) {
          const filePath = resolve(process.cwd(), relPath);
          if (!existsSync(filePath)) continue;
          const original = readFileSync(filePath, "utf-8");
          const count = findBrandingOccurrences(original);
          if (count > 0) {
            writeFileSync(
              filePath,
              replaceBranding(original, brandName),
              "utf-8",
            );
            replaced += count;
          }
        }
        const msg = `Replaced ${replaced} occurrence(s) of 'TherapyContent' with '${brandName}'`;
        if (ci) console.log("[setup]", msg);
        else clack.log.success(msg);
      }
    }

    // ── Done ───────────────────────────────────────────────────────────────
    if (!ci) {
      clack.outro(
        "Setup complete. Review apps/web/.env.local and fill in any remaining placeholders.",
      );
    } else {
      console.log("[setup] Done.");
    }
  });

program.parseAsync(process.argv);
```

## Post-Plan Manual Steps

These items cannot be automated (external service UIs, production secrets) and remain manual. Refer to `docs/manual-tasks/2026-05-21-post-implementation-setup.md` Section 4 and Section 6 for the full instructions:

- **Stripe webhook for local dev:** Run `stripe listen --forward-to localhost:3000/api/webhooks/stripe` before checkout testing. The `--skip-stripe` flag is appropriate in local dev; use `--app-url` only in CI/production.
- **Instagram / Meta App Review:** Cannot be automated. Complete Sections 4a–4c of the runbook manually.
- **Clerk sign-up redirect (`/setup`):** Configure in the Clerk dashboard (Configure → Paths → Sign-up redirect URL: `/setup`). The CLI registers the webhook but cannot change dashboard redirect settings.
- **Resend DNS verification:** DNS records are printed by the CLI. DNS propagation takes up to 48 hours and must be monitored manually in the Resend dashboard.
- **`apps/web/lib/email.ts` `from` address:** Update the hardcoded `noreply@yourdomain.com` on line 7 manually once your domain is verified.
